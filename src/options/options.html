Vimov

Changes apply to open tabs as soon as you save. Settings sync with your Firefox account when add-on sync is on.

Key mappings

Your lines are applied on top of the default mappings, one statement per line.

    Syntax
    map <keys> <command> [option=value …]Bind keys to a command, replacing any existing binding.
    unmap <keys>Remove a binding.
    unmapAllRemove every binding, defaults included.
    # …A comment.

    Keys are the characters they type (j, G, $), or names in angle brackets: <esc> <enter> <tab> <space> <backspace> <up> <f1>. Sequences are written together: gg, g<c-d>.

    Modifiers go before the key: <c-d> Ctrl, <a-p> Alt or Option, <m-k> Cmd or Meta, <s-tab> Shift with a named key. Shifted letters are capitals, so Ctrl+Shift+D is <c-D>. Write <lt> for a literal < before a name.

    A count before a command repeats or scales it: 5j scrolls five steps, 3K moves three tabs right.

    Excluded sites
    
      
    One rule per line: a URL pattern, then optionally the keys to pass through to the page. With no keys, Vimov is off on matching pages. * matches anything within the site name or within the path, as in *.youtube.com; a pattern without a path covers the whole site, and * on its own every site.
