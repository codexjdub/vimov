Welcome to Vimov

Browse with Vim-style keys. Vimov is on in every tab now, the ones that were already open too.

Start here

  • ? on any web page lists every key, your own mappings included; / there filters them.
  • f puts a label on each link; type it to click.
  • o opens the vbar, one box for tabs, bookmarks, history and the web.
  • j k scroll, / finds in the page, Esc cancels.

The keys work on web pages. Firefox doesn’t run extensions on its own pages (this one, the new tab page, about: pages), on addons.mozilla.org, in the PDF viewer or in Reader View. From those, type v and a space in the address bar to search like the vbar.

Turn it off for a site

The Vimov button on the toolbar turns Vimov off for the site you’re on, and back on. In the options you can list sites to leave alone, or pass only some keys to a site, such as a video player’s.

Using vertical tabs?

Vimov follows Firefox’s setting, and knows Zen keeps them down the side: with tabs down the side, J goes down to the next tab and K up to the previous one. If a sidebar extension such as Sidebery or Tree Style Tab shows your tabs, choose Down the side under Tabs in the options.
